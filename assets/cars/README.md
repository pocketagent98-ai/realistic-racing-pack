# cars/

High-detail sports, GT and concept car meshes.

**Accepted formats:** `.glb`, `.gltf`, `.fbx`
**Licences:** CC0-1.0 or CC-BY-4.0 only.

Add realistic (non-low-poly, non-cartoon) car meshes here. No JCBs, tractors,
commercial trucks or blocky models — see the repository README for scope.
