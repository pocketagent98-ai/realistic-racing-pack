# pbr_materials/

Car-paint textures and photoscanned PBR maps.

**Accepted formats:** `.png`, `.jpg` (maps) and `.glb` / `.gltf` (material samples)
**Licences:** CC0-1.0 or CC-BY-4.0 only.

## Currently included

| File | Licence | Author |
|---|---|---|
| `clearcoat_car_paint.glb` | CC0-1.0 | Khronos glTF-Sample-Assets (Ed Mackey) |
| `carbon_fibre.glb` | CC-BY-4.0 | Wayfair / Eric Chadwick |

The **Poly Haven** provider adds photoscanned CC0 texture sets (diffuse,
normal, roughness, AO, metalness, height) at your chosen resolution. The
**ambientCG** provider adds further CC0 material bundles.

Metallic / matte / clearcoat car-paint maps belong here.
