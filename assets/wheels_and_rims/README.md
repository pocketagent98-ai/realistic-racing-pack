# wheels_and_rims/

Modular rims, sports tyres and alloy wheels.

**Accepted formats:** `.glb`, `.gltf`, `.fbx`
**Licences:** CC0-1.0 or CC-BY-4.0 only.

## Sourcing note

Realistic CC0 alloy wheels are scarce. This folder is populated at build time by
the Poly Haven provider (keyword match on *wheel / rim / tyre*) and, when
`SKETCHFAB_TOKEN` is set, by the Sketchfab CC0 provider — which carries a
realistic **Rims & Tyres kit** (`britdawgmasterfunk`, CC0-1.0).

To add a wheel manually, drop the file here and record its licence and author in
`assets/CREDITS.md`.
